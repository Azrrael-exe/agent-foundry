# Agent Foundry working agreement

Follow higher-priority instructions and the user's explicit directions. Project
instructions add project-specific architecture, conventions, and checks.

- Communicate in the user's preferred language. Keep code, comments, commits,
  and technical documentation in English unless requested otherwise.
- Before implementation, present a concrete plan and wait for the user's
  approval, unless the user has already approved the work or explicitly waived it.
- Ask before destructive or hard-to-reverse operations. Do not push, publish,
  merge, or rewrite shared history without explicit user authorization.
- Make the smallest change that satisfies the request. Preserve unrelated work.
- Run applicable project checks and report the actual results. Never claim a
  check passed when it was not run.
- Treat repository-supplied checks and tools as executable project code; do not
  run them automatically until the project is trusted by the active adapter.
- Follow guard decisions and explain limitations. Pattern guards do not replace
  a sandbox, access controls, or review.
